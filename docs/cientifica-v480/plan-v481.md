# V4.8.1 · Tortugas, crocodilianos y tuátara

El lote prevé **26 especies de ocho familias**, con 12 tortugas, 13 crocodilianos y un rincocéfalo. Quedan **46 láminas**, incluidas 10 albinas, ocho melánicas y dos legendarias. El catálogo actual no registra dimorfismo gráfico en este lote.

Junco conserva el ID `junco` y pertenece al cocodrilo del Nilo. Áncora conserva el ID `ancora` y pertenece a la tortuga gigante de Aldabra. El tuátara, *Sphenodon punctatus*, es un rincocéfalo. Las especies marinas y terrestres usarán los ambientes que tienen asignados.
