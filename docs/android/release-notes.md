# El Gran Atlas · Android verificado

Este APK se publica únicamente después de verificar el candidato exacto, su manifiesto, firma permanente y restauración física registrada. No se recompila durante la publicación. El registro docs/android/restoration-validation.json identifica el run, commit, versión, certificado, hash del binario y resultados observados.

Antes de actualizar, conserva dos respaldos externos validados. Con certificado e ID idénticos, la actualización normal preserva los datos; con certificados diferentes se requiere una transición manual autorizada mediante respaldo/restauración. Nunca desinstales una partida sin las copias validadas.

Consulta README_ANDROID_FIRMA_PERMANENTE.md y docs/and3420/prueba-fisica.md para el procedimiento y sus límites.
