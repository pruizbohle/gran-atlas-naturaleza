# Preparación de V4.4.0 · Ungulados

El [inventario inicial](ungulados-candidatos.tsv) recoge 118 registros candidatos del catálogo vigente, con su identificador, nombre científico, etiqueta histórica, dimorfismo y variantes configuradas. Se extrajo de Ungulados, Équidos, Jirafas y afines, Rinocerontes, Suidos, Camélidos, Hipopótamos y familias explícitas equivalentes.

Para cerrar el alcance, cruzar los 997 registros con las familias zoológicas de artiodáctilos terrestres y perisodáctilos, revisar los taxones guardados bajo otras etiquetas y confirmar el tratamiento de los hipopótamos. Conservar los identificadores y las variantes del juego. Validar las identidades legendarias con sus registros activos.

La revisión de arte debe distinguir estructura y forma de las pezuñas, número de dedos, astas, cuernos, colmillos, proporciones y pigmentación, además del dimorfismo documentado. Usar como base el [estándar V4.2.1](../naturalista-v421/estandar.md), la biblioteca de paisajes y el caché separado del laboratorio. El inventario está listo para revisión zoológica antes de generar imágenes.
