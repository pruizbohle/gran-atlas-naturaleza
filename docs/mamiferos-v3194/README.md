Las evaluaciones artísticas son cualitativas. La firma geométrica de 269 contornos distintos excluye color y detalles interiores; no equivale a una prueba automática de identificación visual. Los congéneres próximos conservan estructuras compartidas y necesitan también rasgos de pelaje o el nombre en el tamaño menor.
