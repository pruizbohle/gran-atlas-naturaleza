# 3.38.0 · Doce proyectos curatoriales

Cada diploma se acredita una sola vez al cumplir simultáneamente los requisitos. No otorga libras, conocimiento, materiales, prestigio ni renta. El diploma permanece aunque cambie después la distribución; el montaje vigente se calcula por separado. Las piezas científicas no ocupan vitrinas animales.
