# El Gran Atlas V5.0.11 · ART-07

Base `eaeb392` (V5.0.10) en `audit/aud-01-v501`. Se revisaron variantes que ya figuraban como insuficientes. El visor se usó con el filtro **Insuficiente**, el orden **Prioridad** y la búsqueda por ID. Las comparativas reúnen la lámina normal, la anterior y la propuesta sobre crema y carbón con los WebP de 64, 128, 256 y 512 px. Los candidatos rechazados se conservan como evidencia de revisión.

La selección inicial mostraba 14 casos insuficientes. Cada ficha conserva el diagnóstico original y la decisión sobre el iris. Las fuentes de aves describen el ejemplar típico y orientan anatomía y pigmentación. La presencia de barrado o de otros pigmentos residuales se registra como hipopigmentación interpretativa. En `Hydrictis` se ha descrito el albinismo. La distribución del color de la lámina y el iris siguen siendo decisiones de ilustración.
