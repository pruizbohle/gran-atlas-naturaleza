# Subáreas y alertas de distribución

Las regiones son amplias y el Excel es ilustrativo. Estas decisiones no agregan hexágonos ni un algoritmo de encuentro por subárea: limitan la interpretación de cada presencia y se muestran en los detalles del laboratorio. Las dos filas señaladas como localidad pendiente se conservan sin certificar presencia nativa ni inventar un traslado.

Para conservar intactos los perfiles compartidos, Llanos utiliza `sabana, bosque, rio, humedal`: bosque incluye corredores ribereños compatibles con el jaguar existente. Patagonia utiliza `pradera, bosque, costa, humedal`: el filtro pradera representa los ambientes abiertos/esteparios y conserva el perfil del caracara; humedal permite el cisne. Son configuraciones explícitas de juego, no columnas atribuidas al Excel. No se cambia ni una asignación regional.
