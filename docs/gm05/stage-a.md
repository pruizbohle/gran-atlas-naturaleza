# GM-05A · vista mundial vigente desde 9da9808

Comprobación ejecutada sobre el motor real: 945 identidades, 113 regiones y 1744 pares válidos. Cada par tiene testigo manual y automático con hábitat, hora, estación y protocolo. Ningún nombre científico completo duplicado ni referencia rota. Los cinco grupos de binomio compartido conservan rangos separados; no se interpretan como cinco duplicados demostrados.

Se conciliaron las 1574 filas, con hoja/fila/HX/ESP originales, destino, identidad aprobada o candidatos de rango separados, diferencia y evidencia. Resultado: 1148 concordancias históricas, 415 incorporaciones posteriores, diez conflictos de rango y una diferencia Canis aureus/lupaster. Las 900 filas del catálogo se vinculan con 898 IDs efectivos. Permanecen los 47 IDs adicionales históricos, enumerados individualmente; ninguno se elimina.

La vista derivada de las 209 celdas confirma 103 pobladas y 106 reservadas. Se documenta la discrepancia 209/0 del JSON GM01 sin editarlo. Todos los archivos GM01 se comparan con el commit base mediante SHA256 y bytes.

El registro derivado mantiene las 413 incidencias: **21 resueltas, 22 pendientes, 59 de contexto histórico y 311 sin defecto demostrado**. Las diferencias literales de rareza o nombres de grupos no se convierten en errores de balance; las colisiones reservadas no se convierten en regiones. Cada fila conserva descripción, decisión, evidencia y commit posterior cuando corresponde. Las decisiones de Oceanía/mares ya publicadas no vuelven a aparecer como bloqueos abiertos.

Consultas GBIF nuevas respaldan únicamente nombres/rangos prioritarios; respuestas completas conservadas. Panthera pardus tulliana devuelve HIGHERRANK, no una sinonimia aprobada. Gorilla beringei beringei no cubre por sí solo todo Gorilla beringei. Canis aureus y C. lupaster siguen distintos. Los complejos de Arapaima, Electrophorus y Leopardus permanecen limitados por la intención/localidad fuente; no se inventan nuevas asignaciones. GBIF registra colocola como sinónimo de colocolo, pero eso no soluciona la circunscripción heredada amplia del gato de pajonal. Véase taxonomic-decisions.json.

Las 945 filas operativas incluyen clasificación, rareza, regiones y configuración; 487 perfiles históricos no representan familia explícita. Se señala esa ausencia de esquema sin inventar una familia certificada. La verificación no equivale a haber consultado una autoridad externa individual para los 945 taxones ni a validar cada localidad.
