# El Gran Atlas v3.1 — Campo y Cuaderno

Actualización **exclusivamente visual**. No modifica economía, estudios, guardado `gran_atlas_v05`, sprites ni lista de especies.

## Campo
- Escenarios SVG diferenciados según hábitat, con iluminación por horario.
- Animal protagonista y tarjeta de avistamiento con animación ligera.
- Botón de observación destacado y filtros plegables.
- Diario de expedición y ayudas de prueba accesibles.

## Cuaderno
- Ficha tipo folio del naturalista con retrato, rareza y nombre científico cuando corresponde.
- Cinco sellos de investigación y porcentajes, sin cambiar los requisitos.
- Variantes, dimorfismo, avistamientos, alimentación, clasificación y ecología.

## Verificaciones
Probar en Android: observar, cambiar condiciones, abrir Cuaderno, seleccionar especies, investigar y conservar la partida tras cerrar. Probar los otros ocho módulos y operación offline. Mantener un respaldo JSON externo.

Esta versión sigue usando la aplicación Alpha `com.elgranatlas.naturaleza.alpha`. La firma de desarrollo de GitHub Actions puede variar entre APK: **no desinstalar una versión con progreso sin respaldarla antes**.
