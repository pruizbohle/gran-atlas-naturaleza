# Beta 3.10.1 — Corrección de ecología africana

Un parche mínimo: el normalizador global de ecología sustituía hábitats y horarios específicos de 17 animales incluidos en Lagos del Rift y Seychelles/Aldabra. Se conserva la ecología declarada para esas especies tras normalizar, sin modificar el resto del catálogo. Esto recupera especies imposibles de observar (como león y guepardo en Rift) y hábitats/estaciones erróneos. El formato de guardado sigue siendo `el-gran-atlas-save` v1, clave `gran_atlas_v05`.

Instalación independiente `com.elgranatlas.naturaleza.beta3101`; exportar JSON de 3.10 e importar en 3.10.1.
